# Appointments Module

The Appointments module extends M.O.M. from acute health logging into broader parent operations.

## MVP scope

- Add appointments or family deadlines.
- Attach each item to a child or the whole family.
- Capture type, date/time, location, provider/contact, questions, documents, follow-up actions, and notes.
- Filter by child/scope and status.
- Mark items done or reopen them.
- Copy a single prep brief.
- Copy a filtered schedule summary.

## Product framing

This is not a replacement for a calendar, clinical guidance, school systems, or emergency services. It is a structured caregiver prep board that helps tired parents avoid losing context before appointments.

## UX rationale

Dose & Go answers: “What did we give?”
Fever Log answers: “What happened?”
Appointments answers: “What do we need to ask or do next?”

The prep brief connects recent fever and medication context to the upcoming appointment without making recommendations.
